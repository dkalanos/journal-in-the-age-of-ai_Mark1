# Procedure

1. Fix the primitives (held constant throughout): agents N with n >= 2; a finite state set S drawn i.i.d. from full-support rho; finite actions A_i and consequences X; payoffs pi_i; the mechanism vocabulary Theta with theta: A -> Delta(X); and the objective assignment tau: S -> Theta. Each agent holds an awareness partition P_i and expressible theories M(P_i) = {m: P_i -> Theta}. It observes its cell at the start of each period and (a, x_i) at the end, and retains the deliberative record r_i. The analyst record r_bar_i adds state labels.
2. Choice within a fixed language: given the acting belief mu_i and the empirical conjecture q_i, compute sigma_i_star cellwise by equation (2) and the subjective value U_i by equation (3). Replace sigma_i by sigma_i_star iff T*(U_i(sigma_i_star) - U_i(sigma_i)) > kappa_i; otherwise, or when mu_i is undefined, carry sigma_i forward.
3. Proposition 5.1: Bayesian or judged conditioning reweights a distribution on its fixed domain M(P_i). Every element is cell-constant, so every posterior and every policy optimal against one is P_i-measurable, and no update enlarges the domain.
4. On a stable stretch with constant profile sigma, each state receives a(s) = (sigma_j(C_{P_j}(s)))_j. Compute agent i's on-path conditional p_i*(.|C,a) by equation (4), which mixes the mechanisms of the states in C receiving profile a.
5. Testing (Definition 6.1, Appendix A, Lemma D.1): for each admitted theory, run the evidence process E_i^m, a convex mixture of betting factors F = 1 + lambda*(1{x in D} - (q(D) + eta)) at each visited pair, initialized at 1. It is a supermartingale under adequacy, so Ville gives Pr(sup E >= exp(b_i)) <= E(t_0)*exp(-b_i). Under recurrent strict inadequacy a fixed positive-weight component has positive expected log-growth (g'(0) = p(D) - q(D) - eta > 0), so E diverges almost surely by the strong law. Reject m permanently when log E_i^m >= b_i. In the exact deterministic case, reject at the first zero-probability consequence. The active set is monotone and eventually constant.
6. Judged updating: the reference posterior updates by token likelihoods marg_i m(C)(a)(x_i); the acting belief is its restriction to the active set. Dissonance is an empty active set. Proposition 6.5: if all profile-adequate theories are active at t_0, Lemma D.1 makes the eventual active set empty almost surely exactly when every theory is eta-inadequate (exposure). For a non-exposed profile, conditional Ville bounds rejection of an active adequate theory by E_i^m(t_0)*exp(-b_i).
7. Repair (Section 7, Proposition D.2): for each candidate strict refinement P', recode the analyst record and apply the repair test (equation 6) at every nonempty (C',a). Because the constraints involve one cell at a time, M_hat_i^R(P', r_bar_i) is the product over cells of Theta_i^R(C'|r_bar_i), so P' is restorative iff every cell is repair-coherent. Enumerate partitions to obtain the minimally restorative set R(P_i, r_bar_i).
8. Theorem 7.4: couple two worlds tau != tau' that agree on joint consequence laws at all reachable pairs, using common state draws, common seeds for production, formulation, bridge-prior selection and tie-breaking, and identity-coupled consequence draws. Induct over periods: identical histories give identical partitions, policies and action profiles, hence identical records and outputs. A common output distribution cannot put probability one on two disjoint correctness sets. Proposition 7.5: sufficiency for each candidate is refinement of each P^tau', hence refinement of their join.
9. Economics of inquiry (Section 8): at a dissonant record, enumerate the deliberative groupings G of the tokens. For each group compute Theta_i(g) by the grouping test (counts >= n_bar) and keep the coherent groupings. For each coherent G compute the per-token robust gain Delta_i^G(t,a_i): the minimum over rival actions and over Theta_i(g(t)) of the payoff difference between a_i and the standing action. Then compute Lfine (best action per current-cell/group intersection), Lcur (best single action per current cell) and J = Lfine - Lcur, and set B_hat_i = (T/|r_i|)*max({0} union {J}).
10. Proposition 8.4: finiteness makes every term well defined. The sum of maxima is at least the maximum of sums, giving J >= 0. Each per-token gain is at most max pi_i - min pi_i, and the standing action gives Lcur >= 0, so 0 <= B_hat_i <= T*(max pi_i - min pi_i). The election rule is: elect iff lambda_i^(k_i)*B_hat_i >= gamma_i. B_hat_i > 0 iff some coherent G has J > 0.
11. Pivot (Section 9): after successful production of P_i', the formulation rule draws m' from M_hat_i^R(P_i', r_bar_i) and the agent forms a full-support bridge prior mu_i^+. Then Coh_i = mu_i^+(m') / sum over M_hat_i^R of mu_i^+. For warrant, fix an analyst assessment (calT, nu) and compute W(o) = nu(A_o | r_bar_i, h_i, O_i = o).
12. Theorem 9.2: with Z = (r_bar_i, h_i), truth-blindness and record-measurability make the output kernel K(.|Z) independent of the candidate. Hence Pr(tau', O in B | Z) = nu(tau'|Z)*K(B|Z), so O is independent of tau' given Z, and W(o) = nu(A_o | Z) after summing over A_o. Corollary 9.3: expressing each candidate requires sufficiency for it, hence refinement of the join of Proposition 7.5.
13. Dynamics (Section 10, Appendix B): Theorem 10.4(a): the total cell count sum_i |P_i| is an integer in [n, n|S|] that rises at each success and never falls, so there are at most n*(|S| - 1) refinements. (b): since B_hat_i <= T*Delta pi_i, the election condition fails once lambda_i^(k) < gamma_i/(T*Delta pi_i), at a finite k because lambda -> 0; the counter resets only at the finitely many successes. (c): after G* = max(last refinement, last election), languages are fixed and every dissonance event fails the threshold. (d): on the eventually-constant-profile event, couple to an auxiliary constant-profile process and apply Lemma D.1. A nonempty survivor set means never dissonant; an empty one means dissonant stasis.
14. Supporting results: Proposition D.5(i) holds by continuity of the strict no-switch slack at the limit. D.5(ii-a): in the deterministic case a 0-adequate active theory is never rejected. D.5(ii-b): Ville gives exp(-b_i) per agent and a union bound gives persistence probability >= 1 - sum_i exp(-b_i). D.6 follows from SCUE (iii) and Lemma D.1. D.7: component domination plus bounded-increment Wald reasoning gives E[tau_m] <= 2*(b_i + c_m)/d_i^m, hence O(b_i/D_i), and bounded one-period growth gives Omega(b_i). D.9: diagnosticity implies exposure, which by Lemma D.1 empties the active set, contradicting SCUE (iii). D.10: the strict-punishment inequality makes every expressible theory eta-inadequate, hence exposure and diagnosticity.
15. Example 1, dominance: at a cell with label beliefs p0, p1, the gain of action 0 over 1 is p0/2 - (1 - beta/2)*p1 against a rival playing 0 and (1 - beta/2)*p0 - p1/2 against a rival playing 1. So 0 is strictly dominant iff p0 > (2 - beta)*p1; at beta = 1, belief asymmetry yields differentiated constant policies.
16. Example 1, discovery: firm 1 plays 0 and firm 2 plays 1 at states s00 and s11 (T = 2). Firm 1 earns 1 at s00 and 0 at s11, which rejects m^0, m^1 and m^n, so each active set empties. Repairs: of the 15 partitions of 4 states, 10 separate s00 from s11 and the 4 two-cell ones are minimal (row, column, two isolating partitions), so 11 are excluded. The column world agrees on both visited states, so the worst-case success of any truth-blind rule is at most 1/2, and the join of the row and column partitions is the singleton partition.
17. Example 1, leverage: the winning token pins theta^0 (best gain 0); the losing token pins theta^1 (gain 1/2 against either rival action). So Lfine = 1/2. In the one-cell current language, a uniform reversal nets 1/2 - 1/2 = 0, so Lcur = 0, J = 1/2 and B = (2/2)*(1/2) = 1/2; the firm elects iff lambda^(0)/2 >= gamma. Validation stretch over all four states with T = 2 and |r| = 4 (firm 1 on the row policy, firm 2 on the column policy): firm 1 has Lfine = Lcur = J = B = 0; firm 2 has Lfine = 1, Lcur = 0, J = 1 and B = (2/4)*1 = 1/2.
18. Example 1, warrant: the column (or row) refinement pins a unique consistent theory, so Coh = 1. With calT = {row world, column world} and a symmetric nu, the diagonal record has equal likelihood in both worlds, so by Theorem 9.2 W = 1/2 and gap = 1 - 1/2 = 1/2.
19. Example 1, endings: the trap at beta = 1 has both firms on the column policy, pooling everywhere with payoff 1/2, which equals the prediction, so it is a SCUE. The knife edge at beta < 1: pooled off-diagonal play pays beta/2 != 1/2, which triggers dissonance. Persistence at beta < 1: firm 1 on the row law against firm 2 constant at c earns (1 + 1 + 1/2 + 1/2)/4 = 3/4 against (0 + 0 + 1/2 + 1/2)/4 = 1/4. Firm 2's record rejects all constant theories and its balanced record gives B_2 = (2/4)*1 = 1/2. Stasis is permanent if gamma_2 > lambda_2^(k_{2,t_0})*B_hat_2(r_{2,t}) for all later records; gamma_2 > lambda_2^(k_{2,t_0})*T*(max pi_2 - min pi_2) is sufficient.
