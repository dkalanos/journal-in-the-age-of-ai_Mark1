# The other modalities · specified, not built

The record's parts are common to every modality; provenance, the Level 2 definitions and the standard differ
(appendix B.1, C.3 and C.4). Mark 1 builds formal theory. The rest are specified here at the level the protocol needs,
and the modality router refuses them with this file as its reason (Stage 2).

| Modality | Provenance means | A claim is | A pointer names | An anchor holds when |
|---|---|---|---|---|
| Empirical | the code and data that produce each number, and the declared origin of the data | a reported estimate or test | the table cell and the code that produces it | the code re-run yields the cell within tolerance |
| Simulation | code, seeds, parameter ranges, the runs behind each reported pattern | a reported pattern across runs | the runs, seeds and parameter ranges | re-running the named seeds yields the pattern within a stated stochastic tolerance |
| Qualitative | the audit trail from observation to interpretation: materials, coding, memos | an interpretive statement | the excerpt, field note or coded segment, within its access tier | the excerpt exists at the cited location and the coding is traceable to it |
| Verbal theory | the argument structure: premises, claims, the inferential steps between them | a stated conclusion | the premises and the inferential step | the step is stated and the premises it uses are in the record |
| Survey / review | the corpus, the inclusion criteria, the extraction | a synthesis statement | the extracted items that support it | the items are in the corpus and the extraction matches them |

Level 3 for these modalities follows the validity typology SIEVE organizes (statistical-conclusion,
internal, construct and external validity; modality soundness as verification and validation for simulation),
selected by the router so that no modality is judged by another's standard.
