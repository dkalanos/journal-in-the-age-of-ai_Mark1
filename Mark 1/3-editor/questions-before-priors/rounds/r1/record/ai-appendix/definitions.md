# Definitions of record

- **elementary causal mechanism (theta)** — `theta : A -> Delta(X)`. An element of the finite, commonly known vocabulary Theta: a map from action profiles to distributions over consequence profiles, read causally, so that it specifies the consequences that would result from every action profile, including profiles never played. marg_i theta(a) is the X_i-marginal of theta(a). Not to be confused with: An expressible theory (an assignment of mechanisms to awareness cells); the on-path conditional p_i*, which mixes mechanisms.
- **objective assignment (tau) and objective causal system (F)** — `F(. | s, a) = tau(s)(a)`. tau: S -> Theta assigns each state its mechanism; the objective causal system is the response function F. Two states are causally equivalent if they carry the same mechanism, and P^tau is the partition of S into causal-equivalence classes. Not to be confused with: A statistical summary of on-path outcomes; an agent's awareness partition P_i (P^tau is the objective one).
- **awareness partition (P_i)** The partition of S, P_i in Pi(S), with respect to which every consciously available object of agent i (theory, belief, conjecture, policy, question) must be measurable. An awareness cell is an implicit claim that the states it pools are causally alike. The partition is endogenous: its refinements are the formal footprint of insight. Not to be confused with: An information partition about the realized state in the usual sense; inattention or model selection, which the modeling commitments of section 3.5 distinguish from unawareness.
- **expressible theories (M(P_i))** — `M(P_i) = {m : P_i -> Theta}`. The cell-constant mechanism assignments on P_i; theory m predicts x_i ~ marg_i m(C)(a) at cell C under profile a. Restricting theories to a single mechanism per cell is deliberate: if arbitrary per-cell distributions were expressible, no experience could reject the class. Not to be confused with: Conjectures q_i about rival play, which are strategic claims and are not tested; arbitrary conditional distributions per cell.
- **sufficient partition** — `P sufficient for tau'  <=>  P refines P^tau'`. P is sufficient for an assignment tau' if tau' is constant on every cell of P, equivalently if P refines P^tau'. The objective assignment is expressible for agent i if and only if P_i is sufficient for tau. Not to be confused with: Statistical sufficiency; a restorative refinement, which need not be sufficient for tau.
- **conjecture (q_i)** — `q_i : P_i -> Delta(A_-i)`. A P_i-measurable belief about rival play; a strategic claim about what other agents will do, updated empirically from observed play. Not to be confused with: A theory (a causal claim about the objective system); the diagnostic apparatus tests theories, not conjectures.
- **deliberative record (r_i) and tokens** The retained episodes (C_{P_i}(s), a, x_i), each a token, which can be retrospectively recoded after the agent acquires a new distinction; before acquisition neither belief nor action can condition on that distinction. The analyst-level history additionally records s itself. Not to be confused with: The analyst-level history; a sufficient statistic of the data (tokens are retained individually).
- **committed policy and subjective optimality** — `sigma_i(C) in argmax_{a_i in A_i} sum_{m in M(P_i)} mu_i(m) sum_{a_-i in A_-i} q_i(a_-i | C) E_{x ~ m(C)(a_i, a_-i)}[u_i(x_i)]`. At the start of each generation agent i commits to sigma_i: P_i -> A_i solving equation (3) at each cell, holds it for the generation's T episodes, and revises beliefs, conjectures and policies only between generations. When dissonance has made mu_i undefined and no new representation has been produced, the previously committed policy is carried forward. Not to be confused with: Objective optimality against tau; an episode-by-episode best response.
- **generation and episode** Time is divided into generations g = 1, 2, ..., each of T episodes; in each episode a state is drawn i.i.d. from the full-support rho, actions are taken through the committed policies, and a consequence profile is realized. A generation of committed play is the stable data-generating configuration the consistency test needs. Not to be confused with: Overlapping generations of agents; the agents are the same throughout.
- **consequence (x_i)** Everything an episode delivers to agent i (profit, sales, observed reactions), in a finite X_i; the payoff is u_i(x_i). In the running example x_i is the pair (own payoff, observed action profile). Not to be confused with: The payoff u_i(x_i) alone.
- **on-path conditional (p_i*(. | C, a))** — `p_i*(. | C, a) = sum_{s in S(C, a)} rho(s | S(C, a)) marg_i tau(s)(a),  with S(C, a) = {s in C : a(s) = a}`. Agent i's distribution of own consequences at an observation pair (C, a) under a committed profile: a mixture of mechanisms over the states of C at which profile a is played. It is a selection object: rivals with finer partitions condition on distinctions agent i cannot see, so the within-cell state mixture varies with the profile. Not to be confused with: Any mechanism's own conditional marg_i theta(a); the paper says the two must never be conflated.
- **consistency test, passing, and active set (Mhat_i(P_i, r_i))** — `TV(phat_i(. | C, a), marg_i m(C)(a)) <= eta + w(n_i(C, a))  for every (C, a) with n_i(C, a) >= nbar`. With tolerance eta >= 0, minimum count nbar >= 1 and a nonincreasing slack sequence w(.) -> 0, theory m passes if its prediction lies within eta + w(n_i(C, a)) in total variation of the empirical conditional at every observation pair with at least nbar observations; the active set collects the passing theories. The deterministic instance is eta = 0, nbar = 1, w = 0: exact consistency with every retained episode. Not to be confused with: Bayesian updating, which ranks expressible theories but never judges the whole class inadequate; a likelihood-ratio test against an alternative.
- **eta-adequate and eta-inadequate theory** — `TV(p_i*(. | C, a), marg_i m(C)(a)) <= eta at every visited (C, a)`. Under a committed profile, m is eta-adequate if TV(p_i*(. | C, a), marg_i m(C)(a)) <= eta at every visited pair, and eta-inadequate if the inequality fails strictly at some visited pair. Adequacy is relative to the profile's visited pairs. Not to be confused with: Objective correctness (an adequate theory can be false at pooled states or unvisited profiles); passing the finite-sample test (adequacy is the population property the test converges to).
- **judged updating: reference posterior (mubar_i) and acting belief (mu_i)** — `mu_i = mubar_i restricted to Mhat_i(P_i, r_i), renormalized`. Beliefs carry two tiers. The reference posterior begins at a full-support prior on M(P_i) and updates by likelihoods alone, never conditioned on the test; the acting belief is the reference posterior restricted and renormalized to the current active set, and is undefined when the active set is empty. After a refinement both tiers restart from the bridge prior on the expanded space. Not to be confused with: A single posterior conditioned on the test; ordinary Bayesian conditioning, to which judged updating reduces only in the deterministic case.
- **causal dissonance** — `Mhat_i(P_i, r_i) = emptyset`. Agent i experiences causal dissonance at the end of a generation if its active set is empty: every expressible theory is rejected while the expressible set itself remains. The question it poses (what unrepresented difference among the pooled states explains the heterogeneity of their consequences?) has a determinate defect but not a determinate answer; it is localized, directed and semantically open. Not to be confused with: A low or declining posterior (the misspecified posterior grows confident, not alarmed); strategic error about rivals; cognitive dissonance in the psychological sense.
- **exposed awareness and concealing profile** Under a committed profile, P_i is exposed if every m in M(P_i) is eta-inadequate. A committed profile is concealing for agent i if some expressible theory is eta-adequate under it while false as a claim about tau at some state its cells cover. Not to be confused with: Dissonance itself: exposure is a property of the profile, dissonance its almost-sure eventual consequence (Proposition 5.5).
- **restorative and minimally restorative refinement (R(P_i, r_i))** — `P_i < P' (strict refinement) and Mhat_i(P', r_i) != emptyset`. P' is restorative at (P_i, r_i) if it strictly refines P_i and the active set on the recoded record is nonempty; it is minimally restorative if no restorative P'' lies strictly between P_i and P'. R(P_i, r_i) is the set of minimally restorative refinements. Not to be confused with: A refinement sufficient for tau (a restorative refinement may be false, as the column refinement is); the technology's range, which kappa may restrict further.
- **coherent cell and mutually incoherent token sets** A cell of a refinement is coherent if some single mechanism passes the test on the cell's recoded observations; token sets are mutually incoherent when no single mechanism accommodates their union. Every restorative refinement must separate mutually incoherent sets. Not to be confused with: Bayesian coherence of beliefs; representation-relative coherence (the confidence a new language awards its own theories).
- **irreparable record** — `R(P_i, r_i) = emptyset`. A dissonant record with R(P_i, r_i) = emptyset: no refinement of S restores a nonempty active set. Possible only with stochastic mechanisms (an unlucky finite sample at a single state outside the tolerance of every mechanism); then B_i = 0 and the technology fails surely. Not to be confused with: Zero-leverage dissonance, where repairs exist but none changes any represented action comparison.
- **representation-producing technology (phi_i), truth-blind, and complexity ordering (kappa)** — `phi_i : (P_i, r_i) -> {P_i} union R(P_i, r_i)`. A possibly randomized map from (P_i, r_i) to {P_i} union R(P_i, r_i): it fails, returning the current partition, or succeeds, producing a minimally restorative refinement; it fails surely when R is empty. Truth-blind: its output distribution depends only on (P_i, r_i), never directly on tau. A complexity ordering kappa on refinements may restrict the range; it is a primitive of the technology, not an object of the agent's optimization. Not to be confused with: A prior over named future theories (the agent cannot name, weight or condition on a candidate refinement before success); a signal correlated with tau.
- **election (epsilon_i), inquiry cost (gamma_i), and delabeled success weight (lambda_i)** — `epsilon_i = 1  iff  lambda_i B_i(r_i) >= gamma_i`. The technology operates only when agent i experiences dissonance and elects inquiry, epsilon_i = 1, at cost gamma_i > 0 in payoff units. lambda_i in (0, 1] is a subjective probability that an elected episode produces a usable refinement, defined on the event of success alone and not on the identities of possible outputs. Awareness is cumulative: acquired distinctions are never lost. Not to be confused with: A probability distribution over identified candidate refinements; the intensity or duration of inquiry, which the model does not price.
- **pinned structure (Lambda_i(r_i)), pinned distinctions, and Theta_i(t)** — `Theta_i(t) = { m'(C'_{P'}(t)) : P' in R(P_i, r_i), m' in Mhat_i(P', r_i) }`. Each restorative refinement induces, through recoding, a partition of the retained tokens; the pinned structure is the meet (finest common coarsening) of these induced token partitions. A token rule is implementable whichever repair arrives exactly when it is Lambda_i-measurable, and the separations Lambda_i preserves are pinned distinctions. Theta_i(t) collects the mechanisms that some admissible repair's active theory assigns to token t's cell; it is nonempty because restorative active sets are nonempty. Not to be confused with: The join of the repairs (the pinned structure is their meet); the cells of any particular repair.
- **retained-record leverage (B_i(r_i)) and the subjective recurrence premise** — `B_i(r_i) = max_{psi Lambda_i-measurable} sum_{t in r_i} min_{a_-i in A_-i} min_{theta in Theta_i(t)} ( E_{x ~ theta(psi(t), a_-i)}[u_i(x_i)] - E_{x ~ theta(sigma_i(t), a_-i)}[u_i(x_i)] )`. Under the premise that the agent values a prospective repair over one anticipated recurrence of its retained record, token for token, the leverage of inquiry at a dissonant record with R nonempty is the maximum over Lambda_i-measurable rules psi of the summed worst-case gain of psi(t) over the carried-forward action sigma_i(t), the worst case taken over rival actions and over Theta_i(t). B_i = 0 when there is no dissonance or when R is empty. It is computable from the record with (Theta, u_i) and invariant across repairs. Not to be confused with: The expected value of information; the objective value of repair (B_i understates it when consequences conceal forgone values); a per-episode or per-generation rate (the horizon is one recurrence of the whole record).
- **participation rule and represented value of inquiry** — `lambda_i B_i(r_i) - gamma_i`. Electing inquiry has represented value lambda_i B_i(r_i) - gamma_i, and agent i elects if and only if lambda_i B_i(r_i) >= gamma_i. It is a non-Bayesian criterion operating where the posterior is undefined, quantifying only over retained tokens and their recorded outcomes. Not to be confused with: A Bayesian expected-utility comparison over candidate theories.
- **counterfactual transparency** The degree to which consequences identify forgone values; it lives in the inner minimum over Theta_i(t) of equation (6). When a lost episode's record pins the mechanism every repair must assign it (winner-take-all markets), Theta_i(t) is a singleton and the bound is exact; when consequences conceal forgone values, Theta_i(t) is large and B_i understates the objective value of repair. Not to be confused with: Exposure (whether play makes the falsity of the language visible), a separate dimension of an environment's diagnosticity.
- **formulation, bridge prior (mu_i^+), and representation-relative coherence** After successful production yields P_i', formulation selects a theory m' in Mhat_i(P_i', r_i) on the recoded record, and the agent forms a full-support bridge prior mu_i^+ in Delta(M(P_i')), not determined by the pre-dissonance belief, from which ordinary updating resumes. Representation-relative coherence is mu_i^+ renormalized on the active set: the confidence the new language awards its own theories. Not to be confused with: Warrant (what the evidence licenses); a Bayesian update of the old belief (the domains differ).
- **reflective assessment problem ((T, nu)), selection-adjusted warrant (W), and warrant gap (G)** — `G = Coh(m') - W`. A reflective assessment problem is a finite set T of candidate objective assignments with a full-support reflective prior nu. Given the record and a successful production-and-formulation event, W is the nu-posterior probability that m' is objectively correct, i.e. tau'(s) = m'(C_{P_i'}(s)) for all s, conditional on the record and on the production event. G is the representation-relative coherence probability of m' minus W. Not to be confused with: The agent's own posterior (the assessment is generally not expressible by the agent, Corollary 8.3); post-insight confidence.
- **self-confirming unawareness equilibrium (SCUE)** A profile of epistemic states xi_i = (P_i, r_i, mubar_i, q_i, sigma_i), with acting beliefs by judged updating, such that under the play it induces (i) each sigma_i is subjectively optimal (equation (3)); (ii) each q_i agrees with the play induced by sigma_-i at every on-path cell; (iii) no dissonance occurs: each active set is almost surely eventually nonempty and each acting belief is supported on eta-adequate theories; (iv) no agent elects inquiry: lambda_i B_i(r_i) < gamma_i along the induced records. The record belongs in the state. Not to be confused with: Nash equilibrium; self-confirming equilibrium of the fixed-language tradition (conditions (i)-(ii) only); a statement that play converges.
- **Bayesian world and dissonant stasis** An agent lives in a Bayesian world when it is eventually never dissonant: models fit, questions are dead, inquiry is priced below cost. It is in dissonant stasis when dissonance recurs while lambda_i B_i < gamma_i, in particular whenever B_i = 0, as at irreparable records. Not to be confused with: Convergence of play; a pathology of the model (zero-leverage stasis is rational anomaly tolerance).
- **diagnostic environment and payoff-relevantly false theory** A theory is payoff-relevantly false if it is false at some state where the truth would change its holder's optimal action. The primitives (Theta, tau, rho, u) are diagnostic if, under every profile sustainable in a SCUE, every payoff-relevantly false expressible theory is eta-inadequate. Not to be confused with: Exposure under one particular profile; an environment in which no false theory can be held at all.
- **recurrent and frozen observation pair (appendix A)** Under an eventually constant committed profile sigma*, a pair (C, a) is recurrent if S_{sigma*}(C, a) != emptyset and frozen otherwise. A frozen pair is visited at most finitely often, so its test constraint is eventually constant; a recurrent pair's count diverges almost surely. Not to be confused with: Recurrent states of a Markov chain.
- **row law, column world, factor refinements, and beta (running example)** — `tau(s_rc) = theta^r;  tau'(s_rc) = theta^c`. In the four-state laboratory the objective assignment is the row law tau(s_rc) = theta^r, and the column world is the observationally equivalent assignment tau'(s_rc) = theta^c. The row and column partitions are the one-coordinate (factor) refinements a factor-seeking technology produces. The demand parameter beta in [0, 1] is the share of unit value a customer pays when the firms pool on the wrong architecture; the baseline sets beta = 1. Not to be confused with: The row and column partitions as awareness (either firm may hold either); the true law with the agent's theory.
- **insight (formal footprint)** Everything the paper calls insight is the production of a distinction that separates states carrying different mechanisms: the refinement of the awareness partition the technology returns. The conscious act itself is not represented; its products and its price are. Not to be confused with: Evidence (Theorem 8.2: the insight is not evidence); expansion of the mechanism vocabulary Theta, which the paper leaves outside.
